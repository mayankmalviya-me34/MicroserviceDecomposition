You are a software architect.

Given a function or class from a software system,
infer the following semantic information:

1. Intent:
   - Create
   - Read
   - Update
   - Delete
   - Process

2. Domain Entity:
   - The core business or architectural concept
   - Ignore framework, configuration, and test artifacts

3. Business Role:
   - The responsibility of the component
   - Expressed as a service-level abstraction

Input:
- Fully Qualified Name (FQN)
- Class name
- Method name

Output format (JSON only):
{
  "intent": "<Intent>",
  "domain_entity": "<Domain Entity>",
  "business_role": "<Business Role>"
}
